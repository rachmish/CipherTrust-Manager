## Administration (part 1)

### Reference
**Release model (v2.25 FR)**: semver MAJOR.MINOR.PATCH. LTS=4y support (2y scheduled patches); FR=2y. Current LTS 2.23.x (patches to Q2 2028), 2.11.x-LTS (patches to Q4 2026); 2.26 will be LTS. k160 not supported on 2.25. Upgrade: standalone/remove-rebuild up to 3 minors; online in-place cluster 1 minor (not 2.21->2.22; none from <=2.21, go to 2.21.3 then rebuild); offline in-place only LTS->LTS (2.11.8->2.23.0). Force flag: `sudo /opt/keysecure/ks_upgrade.sh -f <archive> -o`. <2.8 must go via 2.8.1. k160 Mk I: always remove/rebuild.
**Identities**: clients = unregistered / public (ksctl, NAE, web-ui+api-playground; fixed ids nae c5890024-a6d4-408d-a592-5d4d5807c722, web-ui 17771cf2-f80b-4eb5-a19b-a2d0032179c3, ksctl 5ffb6fac-2cb5-4b91-8183-e20ad3b62577) / confidential (registered; only these authenticate). Users: local, LDAP, OIDC. `ksadmin` = OS admin (SSH key/console only, no UI/ksctl/API; `kscfg`, upgrades, `sudo -l`). Initial `admin`/`admin` must be changed at first login (`ksctl changepw --user admin`). Last Application Admin cannot be deleted. Interfaces: web 80/443 (UI+REST), ssh 22, nae 9000, kmip 5696, snmp 161, preboot (only with disk encryption; only cert ops). Port 9100 reserved. Changing port of default NAE/KMIP/WEB iface restarts all cluster nodes.
**User props**: username immutable, case-insensitive, no `/ | \ < >`, not `global`; `expires_at` (RFC3339; past=error; only admin/User Admins; extending reactivates); `allowed_client_types` (empty=none; not enforced on admin); `allowed_auth_methods`: password(default) | user_certificate | "password","user_certificate" | password_with_user_certificate (needs certificate_subject_dn) | ""; `prevent_ui_login`; `is_domain_user`; `password_policy`; `--userconnection <ldap/oidc conn>` pre-creates ext user (OIDC username must equal sub claim). Password hash iterations default 10000 (PASSWORD_HASH_ITERATIONS). Ext users login `conn|user` (also `\` `/`); NAE: `domain-id|conn|user`. Deleting LDAP conn deletes its users.
**LDAP (Access Mgmt>LDAP, root domain only; license req.)**: required `--name --server-url --root-dn --user-id-field`(uid-field); groupmaps need all six: bind-dn bind-password group-base-dn group-id-field group-filter group-member-field; optional guid-field search-filter disable-auto-create user_dn_field(AD default distinguishedName) insecure-skip-verify root-cas (LDAPS). name/strategy/bind-pass immutable. AD "Protected Users" unsupported. `ksctl connections test|create ldap`.
**OIDC (not ksctl login)**: flows implicit(form_post, id_token; default) / authorization_code (needs client secret, `--flow-type authorization_code`). Redirect `https://<host>/api/v1/auth/oidc-callback` per node; post_logout `https://<host>/api/v1/oidc-callback`. Claims: sub required; name, email optional; `--groups-claim` (default groups; UserInfo fallback code flow only), `--username-claim` (default sub; template `{{.custom.username}}`), scope default `openid email profile` (<=254 chars), `--discovery-uri`, `--disable-auto-create`. Non-public IdP CA: add external CA + trust for user-management & platform (`ksctl trusted-ca-cert create-many`). NTP required. Logout = single logout. OIDC/LDAP/cert login: root-domain users only.
**Cert login (local users)**: user cert_subject_dn (CN mandatory; no self-signed); CA must be external CA with user_authentication on + in WEB iface trusted CAs; restart web service; CRL checked ("cannot log in the user with a revoked certificate"; CRL unreachable=allowed).
**Tokens**: JWT valid 5 min; refresh token UI idle 30 min (UI idle logout 10 min); `ksctl login` default 30d (`--days/--hours`); `MAXIMUM_REFRESH_TOKEN_LIFETIME` property overrides. `POST /api/v1/auth/tokens/` (name,password[,domain,auth_domain] | grant_type client_credential+client_id with client cert), `/v1/auth/revoke`, `/v1/auth/logout`, `GET /v1/auth/tokens?user_id=`, `DELETE /v1/auth/tokens/{id}`, `GET /v1/auth/self/domains/`. `ksctl tokens create --user --password --issue-rt|--refresh-token`, `ksctl tokens rotate-auth-key --type ecdsa --curve p256|hmac` (ES256 default since 2.15), `ksctl tokens self-domains`.
**Interface settings**: modes (`-m`): no-tls-pw-opt, no-tls-pw-req, unauth-tls-pw-opt(NAE default), tls-pw-opt, tls-pw-req(user delegation), tls-cert-opt-pw-opt(WEB only), tls-cert-pw-opt(impersonation; KMIP), tls-cert-and-pw. KMIP allows only tls-cert-pw-opt/tls-cert-and-pw. `cert_user_field` default CN (E_ND etc; WEB CN only). TLS 1.0/1.1 deprecated; TLS1.3 ciphers not configurable; `--tls-ciphers-file`, `-e/-i tls_1_2/tls_1_3`, `--tls-groups-file`, `ksctl interfaces restore-default-tls-ciphers --name`. `-d <conn>` default auth connection. `--trusted-local-cas/--trusted-external-cas`, `--auto-gen-ca-id <id>|""`, `--local-auto-gen-attributes-file`, `--allow-unregistered true|false` (NAE; new=false), `--mask-system-groups`. Cert: `interfaces certificate get|modify --name --format pem|pkcs12 --file --private-key-password [--skip_validation]`, `use-certificate --name X --copy-from Y --pending-renewal`, `auto-gen-server-cert --name --pending-renewal`, `renewal-cert upload|get|delete|apply`, `csr add|get`. Chain order PEM: key first; PKCS12: key last. Preboot cert RSA-2048/4096, default CN preboot.ciphertrustmanager.local. Cert expiry records: <=91d weekly, <=7d/expired daily. `dke.` SAN prefix skips client cert verification. Custom WEB iface: CCKM/CTE/ADP only (CTE clients not registered to it; default port 8080). Create/delete: `interfaces create --type nae|kmip|snmp -o <port>`, `delete -n`; enable/disable only ssh/kmip/nae. PQC groups (X25519MLKEM768, SecP256r1MLKEM768, MLKEM512/768/1024) off by default; SSH kex `ksctl ssh kex get|modify --kex-algo-file`.
**Clients/regtokens/profiles**: `ksctl clientmgmt profiles create|get|list|update|delete --ca_id --csr-params --groups --cert-duration`; `clientmgmt tokens create --ca-id --cert-duration --client-mgmt-profile-id --life-time (unlimited default) --max-clients (100 default) --name-prefix --labels`; `clientmgmt clients revoke|delete --client-id [--revoke-reason] [--nowarning]`, `renew`, `self renew` (default cert 730d; keep Subject DN unique; `--do-not-modify-subject-dn`, `--subject-dn-field-to-modify`). REST: `POST /v1/client-management/clients`, `/v1/client-management/regtokens`, `/v1/data-protection/client-profiles/{id}`. Clients auto-join "All Clients" group. DSF Hubs regtoken label `ncryptify-reserved/dsf-managed:true` (CLI/API only), then `ksctl groups addclient`. Client cert expiry records daily.
**Password policy** (global cannot be deleted; local users only; custom policies domain-scoped; deleted->users fall back to global): defaults min8/max30, upper1 lower1 digit1 other1, history 5 (0-20), lockout none, lifetime 0=never, min change interval 1 day, reminder days 0-30 (14 new; SMTP+daily 12AM UTC job). `ksctl users pwdpolicy create|get|list|update|delete --policy-name --minlength --maxlength --minupper --minlower --mindig --minother --history --lifetime --pwdchngdays -f "[0,5,30]"`; unlock `ksctl users modify --id <id> -u`.
**Key policies (REST only, not NAE/KMIP)**: `ksctl key-policy create --name --description --label-selector env=x --permissions '{"groups":{"ReadKey":["g"]}}'|update|get|list [--labels]|delete --id` (selector ops `=`,`in`).
**ABAC policies**: Policy = actions + allow/deny + conditions; `ksctl policy create --jsonfile`, `ksctl polattach create --polid --prinjson` (`{}`=all). IP allow-list: effect deny + negate true + actions ["IssueJWT"], path `context.environment.client_ip`; ports `context.environment.interface.port|name|type`(nae/kmip/web); app `context.environment.principal.client_app`. IP policies skip anonymous NAE/KMIP. Banners: `ksctl banners get|update --name pre-auth|post-auth --message|--file` (Markdown, admin root).
**Groups**: system groups: admin, Key Admins, Key Users, Restricted Key Users, User Admins, Domain Admins, CA Admins, Client Admins, Connection Admins, CCKM Admins/Users, CTE Admins/Clients, Audit Admins, Backup/Restore Admins, Domain Backup/Restore Admins, HSM Admins, License Admins, Read-Only Admins, System Admins (LDAP/OIDC conn, logs), Cluster Info Viewers, Migration Split Key Admins, DSF Hubs, DDC*, ADP Admins/Clients. Non-admin users need Key Users to create keys. Group maps: strategy ldap|oidc + connection + external group name, per domain. Custom CTE groups via UI Access Management>Groups.
**Domains**: root default; validated 100 (k170v)/1000 other; license required; <=10 levels share cert chain; default CA duration <= parent, max 10y; `allow-user-mgmt` + `is_domain_user`; HSM-anchored (Luna only; fixed at create; HSM KEK label; rotate KEK; backup needs same partition); deleting does not purge data. Root-only: NTP, LDAP. Login: `ksctl login --domain`, `--auth_domain`. Redirect: `ksctl domains log-forwarders-redirection enable|disable|status` (default on new; off if created <2.16), `domains syslog-redirection`.
**Services**: `ksctl services status [-o]|restart [--service-names nae-kmip,web] [--delay]|reset` (reset wipes all data). **Properties**: `ksctl properties modify --name ENABLE_KMIP_ACTIVITY_LOGS|ENABLE_NAE_ACTIVITY_LOGS --value true` (perf impact).
**Root of trust HSM**: `ksctl hsm setup <luna|lunapci|lunatct|aws|dpod|ibm-hpcs|k160|nshield|protectserver|gcp-cloud-hsm> [--reset --delay 5 ...]`; luna: --hsm-host --partition-name --partition-password --serial --server-cert-file --client-cert-file --client-cert-key-file (NTLS) or --partition-identity-file (STC, fw>=7.7.0; port 1792 outbound; partition >=1536 bytes). `hsm servers add`, `hsm clients stcidentity download`. Keys: `<prefix>-encryption-key` AES-256, `<prefix>-mac-key` HMAC-256 (DARKSTAR- prefix active immediately). `ksctl rot-keys list|get|rotate [--id]|delete --id [--force]`. Same-type HSMs only; hybrid vs shared (`--shared-hsm-partition`, backup `--tied-to-hsm`). Luna fw pairs 7.2.0/7.0.3, 7.4.0/7.3.3, 7.7.0/7.3.3, 7.8.4, 7.8.5, 7.9.0; CM<=2.16 incompatible with fw>=7.8.4.
**Clusters**: max 20 nodes (rec. 4-6); ports 5432 + 2380 bidirectional; same NTP & firmware; hostname [a-z0-9-]; node-local: debug/KMIP/NAE logs, CM license, interface certs. One join at a time; 60 connection attempts. `ksctl cluster new --host --url|info|summary|errors|nodes list|get --id|nodes delete --id [--force]|delete|csr|nodes create|join|fulljoin --member --newnodehost --newnodeconfig [--shared-hsm-partition]`. Allowlist (per node, kscfg only): `kscfg cluster allowlist add|list|remove --ip`. Node status: Ready, Both Ports are Down, Replication is Down, Consensus Port is Down, Joining 1-5/5. `kscfg cluster-report`.
**FIPS 140-3**: `kscfg system entropy-source -s CPU_JITTER`; `kscfg security-profile set --name fips140-3|none`; `kscfg system reset`; restart `sudo systemctl restart keysecure`. Allowed: AES128/192/256, RSA 2048/3072/4096, no TDES encrypt, no SHA-1 sign, no FF1/FF3/ARIA/ChaCha; NAE TCP modes disallowed; all cluster nodes same profile; interface ciphers GCM/CBC-SHA256+ only.
**Monitoring**: Loki local retention default 240h (`ksctl loki config get|modify --retention-time` multiple of 24h, min 24h; `ksctl loki query_range --server-audit-records|--client-audit-records`). `ksctl records alarm-configs create --name --severity --condition 'input.message == "..."' --description`; `ksctl alarms list --state on`. Alarm states on/off/unknown. Disk Full alarm at 80%. Log forwarders (max 64 conns; ES v7/8, Loki, Syslog; no proxy; CRL checked): `ksctl log-forwarders add|modify elasticsearch|loki|syslog --name --connection-id --index-*/--labels-*/--forward-*`. `ksctl logs download --file --type all-logs|debug-logs|kmip-activity-logs|nae-activity-logs|web-activity-logs [--start-datetime --end-datetime --ca-id]` (System Admins, root; verify with verify-logs.sh: "There is no difference in log files digest."). Prometheus: `ksctl metrics prometheus enable|status|renew-token`; `POST /v1/system/metrics/prometheus/enable|renew-token`, scrape `/api/v1/system/metrics/prometheus` bearer token, root only. Legacy syslog: UDP or TCP+TLS, local0/notice, UTC.
**Quorum**: ops: DeleteKey, AddUserToGroup, ArchiveKey/RecoverKey/RevokeKey/ReActivateKey, CreateLink etc, DeleteDomain, RestoreBackup, DownloadBackup(Key), ManagePolicyAttachment, DeletePolicy, UpdateQuorumProfile, CTE ops. States pre-active (expires 15 min) -> active -> approved -> executed | denied | expired (7d). Requester can't vote. `ksctl quorum-policy activate|deactivate --actions X`, `quorum-policy status`, `quorum activate|approve|deny|revoke|delete|get|list --id [--note]`, `quorum-profiles update --profile-id --approvals --voter-groups --excluded-groups`. **Proxy**: `ksctl proxy add|update|delete|list|test --http-proxy --https-proxy --no-proxy --ca-cert-file [--test-url]`; restart required after add/change; URL-encode special chars in password; state protocol explicitly.
**SNMP** (add iface first): `ksctl snmp communities add --community --source --mib-accesses standard,enterprise`; `snmp users add --user-name --security-level noAuthNoPriv|authNoPriv|authPriv --auth-protocol --priv-protocol [--engine-id]`; `snmp mgmt-stations add --host --version 1|2c|3 --security-name [--notification-type trap|inform --port]`. **SMTP**: `ksctl notification smtp-servers add --server --port --username --emailfrom --smtppw --allow-tcp|list|delete`; `notification email add --emailaddr [--meta]`.

### Workflows
1. Create local user: UI Access Management>Users>Create, or `ksctl users create --name bob --pword X [--expires-at ... --allowed-auth-methods password,user_certificate]`; add to groups.
2. Add LDAP: `ksctl connections test --name myco --strategy=ldap --server-url ldap://h:389 --user-id-field uid --root-dn DC=myco,DC=local --test-username u --test-password p`, then `ksctl connections create ldap ...`; login as `myco|joe`; add group map under Groups>group>Add Group Map.
3. Add OIDC: IdP app with redirect URIs -> `ksctl connections create oidc --name n --client-id id --redirect-uris host/api/v1/auth/oidc-callback --discovery-uri uri [--client-secret s --flow-type authorization_code --groups-claim c]`; ensure NTP.
4. External server cert: `ksctl ca externals upload --cert-infile ca.pem` -> list for id -> `interfaces modify --name nae --trusted-external-cas <id>` -> `--auto-gen-ca-id ""` -> `interfaces certificate modify --name nae --format pem --file chain.pem`. Or CSR on CM: `interfaces csr add --name kmip --common-name X --csr-out-file f`.
5. Cert rollover without downtime: `renewal-cert upload` (not applied) -> clients fetch `renewal-cert get` -> `renewal-cert apply -n nae` (auto-applies at expiry).
6. Register custom client: create client profile (CA/CSR) -> `ksctl clientmgmt tokens create --client-mgmt-profile-id` -> client POST /v1/client-management/clients with registration_token+csr -> keep returned id; token via client_credential grant.
7. Join cluster: same version/NTP/allowlist; on joining node `ksctl cluster fulljoin --member M --newnodehost N --newnodeconfig cfg.yaml` (or UI Admin Settings>Cluster>Join); wait Ready before next. Remove: `cluster nodes delete --id` on another node, then `cluster delete` or reset on removed node.
8. HSM root of trust: back up first (setup resets), NTP sync, `ksctl hsm setup luna --reset ...`; later `rot-keys rotate`.
9. Domain: Admin Settings>Domains>Add Domain (name, admins, optional parent CA, allow-user-mgmt, HSM conn); domain users login with Home Domain.
10. Quorum for DeleteKey: `ksctl quorum-policy activate --actions DeleteKey`; user retries op -> `quorum activate --id` -> approvers `quorum approve --id` -> user retries op.
11. Forward logs: create ES/Loki/Syslog connection in Connection Manager -> `ksctl log-forwarders add <type> --name --connection-id`.
12. Enable FIPS: audit ifaces, set CPU_JITTER entropy, `kscfg security-profile set --name fips140-3`, `kscfg system reset` (destructive).
13. IP allow-list: policy JSON (deny, negate true, IssueJWT) -> `policy create --jsonfile` -> `polattach create --polid --prinjson`; include all cluster client IPs.

### Troubleshooting
- Login blocked after failed attempts -> lockout -> admin `ksctl users modify --id <id> -u`; review pwdpolicy -f thresholds.
- x509: certificate is not valid for any names, but wanted to match localhost -> SSL verify on -> `ksctl login --nosslverify` or trust KeySecure Root CA.
- `login token and client id must exist in ksctl configuration file` (logout) -> no refresh token in config.yaml -> `ksctl login` first.
- Invalid date format for Expiry date -> use RFC3339 (2023-01-28T10:30:35Z).
- "Unregistered client found, please register a client. System may go out of compliance." -> legacy NAE iface allow_unregistered=true; register client.
- "Client registration enforcement enabled. Unregistered client found, please register a new client manually or enable auto registration." -> allow_unregistered=false; register or enable auto registration.
- Client cert from subdomain fails -> only leaf presented -> export issuer CA, add as external CA in root, add to iface trusted CAs.
- Browser not prompting for cert -> CA missing in WEB trusted CAs / web service not restarted / stale cookies.
- LDAP/OIDC unknown user cannot log in -> disable-auto-create true -> pre-create user (OIDC username = sub). OIDC fails intermittently -> NTP drift.
- Interface fails to start in FIPS (non-compliant cert/key or no approved ciphers) -> if any Web iface up fix via UI; else `kscfg security-profile set --name none`, restart keysecure, fix, re-enable.
- Join fails/timeouts -> member offline, version mismatch (since 2.12), bad hostname, ports 5432/2380 blocked, allowlist, restore <10 min before join. Node "down" with growing dataLag -> permanent: `cluster nodes delete` (--force if majority down), reset, rejoin. Don't restart during join (~30 min).
- Custom NAE iface certs replaced after node rejoin -> re-upload with `interfaces use-certificate`/`certificate modify`.
- HSM-tied backup unusable -> its RoT key was deleted; never delete RoT keys with dependent backups.
- CM unavailable after HSM setup -> incompatible Luna fw, or RoT keys created manually post-setup; add extra AWS CloudHSMs promptly.
- Luna setup fails with unclear password error -> HSM policy 21 forces PIN change; check NTP.
- "Not Allowed to clear the log forwarder connections health check alarm" -> fix the connection instead.
- Quorum deactivate error "...in pre-active state. Please activate it." -> DeletePolicy/ManagePolicyAttachment quorum active; go through quorum.
- Whole-system lockout from IP policy -> contact Thales Support (Admin DR cannot fix).

## Administration (part 2)

### Reference
**Scope of this fragment (v2.25):** notification email, backup/restore, scheduler, disk encryption, Connection Manager, upgrade, DNS hosts, ksctl, keys/crypto, MKEK, CA/trusted CA, system info/properties, network diagnostics, reports, key templates. Clustering/HA, NTP, SNMP, alarms, KMIP/NAE setup, audit/syslog admin are NOT in this file (Syslog = Connection Manager log-forwarder). Secrets Mgmt (`ksctl secrets create --data-type password --passwordconfig f.json`, `secrets version`, `secrets listversion`) and DDC/CDP (DB protection via `pdbctl`/GUI "Database Protection") covered elsewhere.
**Notification email:** `ksctl notification email list|delete --id <id>`.
**Backups** (resources via API/ksctl/GUI Admin Settings > Backups; always encrypted by a backup key, default key if none; keys/backups NOT auto-copied across cluster nodes; only ONE backup/restore op at a time).
- Compat: restore onto next 3 minor versions (2.11 -> 2.12-2.14); `--force` overrides; LTS -> next 3 minors + next 2 LTS; no downgrade restore (2.10 -> 2.9 impossible).
- System scope: all domains, keys, users/groups, local+external CAs, certs from local CAs (not interface certs), interface config, policies, banners, CSM customer fragments, audit records, schedules, legacy syslog+connection-mgr conns, LDAP/OIDC conns. EXCLUDED: backup keys, cluster config, DNS hosts, NTP, HSM config, instance name, licenses, interface certs, debug/KMIP-activity/NAE-activity logs, proxy config. Disable local DB audit logging before backup. System restore restarts services; cannot restore onto a cluster node (use remove/rebuild). Domain admins cannot do system backups. `--tied-to-hsm` (system only): restorable only with same active HSM RoT key; rotating/deleting RoT key blocks restore.
- Domain scope: keys/attrs/links, CTE policies, local users+groups, customer fragments, CCKM Projects/Google EKM endpoints/Cryptospaces; no restart; restorable on any node; cannot be HSM-tied; HSM-anchored domain backups need dest domain with same HSM partition (HSM conn only addable at domain creation). Users/groups/CCKM restore only across different CMs. Conflict strategy: Error (keys, users/groups, CTE policies) vs Skip (CCKM). Customer fragments: root domain only, secrets-manager service must be enabled; CSM Admins also need Domain Backup Admins + Domain Restore Admins. Templates are NOT in domain backups.
- Commands: `ksctl backupkeys create [--scope system|domain] [--default]|list|download --id --file|inspect --file|upload [--scope domain] --file`; `ksctl backup create [--scope system|domain] [--description] [--tied-to-hsm] [-k <backupkeyId>] [--filters '<json>'|--filters-jsonfile f]|list|get --id|status|download --id --file|inspect --file|upload [--scope domain] --file|restore --id [--filters|--filters-jsonfile] [--force]|browse-prepare|browse --id --filter|browse-cleanup --id`. Filters: `[{"resourceType":"Keys"|"cte_policies"|"users_groups"|"users"|"customer_fragments","resourceQuery":{...names/ids}}]`. Windows needs `\"` escaping. browse-cleanup auto-runs every 24h.
- SCP/SFTP of system backups: `ksctl scp public-key get|rotate` (rotate breaks scheduled SCP; re-add pubkey to dest `~/.ssh/authorized_keys`); `ksctl backup scp --id --host --port --username --auth-method key|password --protocol scp|sftp --public-key --path-to`; `ksctl backup scp status --id [--scpid]` (kept 4 days, then Audit/Server Records). API status: `/v1/backupStatus`.
**Scheduler** (needs license; not in Community Edition): `ksctl scheduler configs create backup|key-rotation|sync-crl --name --run-at "<5-field cron>" ...|list|get|modify <op> --id|run-now --id|delete --id`; `ksctl scheduler jobs list|get|delete --id`. Cron: min hr dom mon dow; `* / , - ?`; mon/dow names case-insens.; granularity 1 min. Groups (root domain): key rotation=Key Admins, system backup=Backup Admins, domain backup=Domain Backup Admins, pwd-expiry=admin. Backup flags: `--backup-key-id --retention-count N` (default unlimited!) `--do-scp true --conn <scp-conn> --scope domain --filters`. Uploaded backup key needed on EVERY cluster node or schedule fails there. Key-rotation flags: `--key-query-json --metadata-json --deactivate-replaced-key <sec> --replaced-key-state Deactivated|ProtectStop --change-state-after-time <sec>=0+` (the two together; not with deactivate-replaced-key) `--start-time`. System schedulers: system_auto_key_rotation (disabled; midnight; per domain; enable `ksctl scheduler configs modify key-rotation --id <ID> --disabled=false`), system_auto_user_password_expiry_notification (enabled, midnight), system_auto_add_labels_on_composite_keys (labels `ncryptify-reserved/compound=1|2`; hide via HIDE_COMPOSITE_KEY). Key `--rotation-frequency-days` (0=off, max 99999). Sync CRL scheduler: WEB/REST only, not NAE/KMIP.
**Disk encryption:** `ksctl diskenc cryptsetup|status -p|secureboot -i <ssh-privkey> [--trusted-ca-file --server-name | --nosslverify]`; preboot interface (443, default name `preboot.ciphertrustmanager.local`), cert via `ksctl interfaces certificate modify --name preboot --file --format pem|pkcs12` (RSA 2048/4096, key included). Unlock needed every boot; cannot be disabled; key = OpenSSH/PKCS1/PKCS8.
**Connection Manager** (Access Management > Connections; Connection Admins/admin add/edit/delete/test, CCKM Admins test only). Products: CSM, Data Discovery, CTE, Cloud Key Manager, Backup/Restore, HSM-anchored Domains. States: Not tested/Fail/Ready. Max 64 log-forwarder conns total (Elasticsearch+Loki+Syslog). ### Troubleshooting
- Domain restore "Error copying data from backup database" -> key/customer fragment with same name+version but different ID exists -> back up with filters excluding it, or delete the duplicate on target, then restore.
- Restore status call fails/GUI hangs after restore -> WEB port changed in backup -> poll `/v1/backupStatus` for Completed, then reload GUI on new port. `Error: Server error. HTTP status code: 500` during restore = services restarting (normal).
- Second backup/restore rejected -> only one op at a time; wait for `backup status`.
- Scheduled backup fails on some cluster nodes -> backup key not uploaded to all nodes; disk full -> set `--retention-count`/`--do-scp`.
- SCP schedule broke after key rotate -> `scp public-key rotate` invalidates old key; install new pubkey on dest.
- `Resource type ("customer_fragments") is not supported for the current domain` -> non-root domain; use root. Restore logs "Ignoring customer_fragments restoration as it is only supported on the root domain."
- System backup tied to HSM unrestorable -> RoT key rotated/deleted or different HSM partition; rotate original RoT key back to active.
- Upgrade `E: Unable to locate package docker-compose-plugin` (device once ran NextGen KeySecure 1.6/1.7) -> contact support. Lost SSH mid-upgrade -> read `/home/ksadmin/ks_upgrade*`, reboot only after "Upgrade succeeded".
- ksctl `x509: cannot validate certificate for <ip> because it doesn't contain any IP SANs` (CM conn test) -> ext CM web cert lacks IP SAN; reissue with SAN. `tls: failed to verify certificate: x509` for Akeyless -> add CA as trusted CA for service secrets-manager.
- OpenSSL < 1.0.2 clients "ssl handshake error" on NAE/KMIP concurrent conns -> upgrade client >=1.0.2b or set DISABLE_TLS_SESSION_RESUMPTION=true.
- UI idle timeout error "UI idle session timeout must be less than or equal to Maximum refresh token lifetime" -> lower UI_IDLE_SESSION_TIMEOUT or raise MAXIMUM_REFRESH_TOKEN_LIFETIME.
- AWS conn test fails -> clock skew (use NTP/`timedatectl`) or no global STS reachability (set regional STS endpoints; in VPC create STS/EC2/KMS/IAM endpoints). SAP DC test fails right after TU creation -> creds activate after create; retest.
- Luna: CCKM RSA key create fails -> HA partitions in mixed/wrong `key-mgmt-mode`; Luna source key link broken after delete -> re-add conn and partitions in original order, refresh CCKM partition. STC fails -> port 1792 outbound blocked.
- Preboot unlock fails/untrusted -> compare DER SHA-256 fingerprint; supply `--server-name`/hosts entry, or `--nosslverify` (insecure).
- Key not reactivatable via KMIP -> use `ksctl keys reactivate`/REST. In-use CTE key cannot be deleted -> remove from key rules; only CTE Admins delete CTE keys.
- Cert revocation check slow auth -> each CA/OCSP/CRL URL consumes CERT_REV_CHECK_TIMEOUT (5s); lower or fix URL reachability. Cert pasted UI<->REST breaks -> convert with `jq -R --slurp` / `jq -r`.
- Added trusted CA not effective -> microservices need cluster-wide restart (other nodes restart individually on removal).

## NAE-XML interface

### Reference
**Protocol**: NAE-XML (used by CADP; JCE/PKCS#11/.NET compatible). XML header + chunked binary data over a persistent connection, default port **9000**. CM NAE runs on **TLS** by default (Classic KeySecure was plain TCP). Header length max **8192 bytes**. Client may skip version negotiation/auth but then must supply them per request.
**Session order**: connect -> VersionRequest (must be FIRST, else connection closed) -> AuthRequest (immediately after; cannot auth later) -> requests. Unauthenticated = "global" user (only global keys; created keys global). Authenticated: keys owned by that user. Re-auth after reconnect.
**Versions**: 2.2-2.10 and 6.0+ ; use highest. VersionRequest{MessageVersion(1.0),ID,VersionList/Version...} -> VersionResponse{Version,ID,Success,ServerVersion}. Server picks first supported in list; none -> failure + close.
**Auth**: AuthRequest{ID,User,Passwd}. User forms: `ldap-conn|user`; `domain|ldap-conn|user`; `domain||user` (root-domain user in domain); `domain|auth-domain||user` (local user in domain). Domain id or name OK. Other: DeviceInfoRequest (model, Box ID, sw version).
**Interface modes (Admin Settings > Interfaces > nae)**: "TLS, verify client cert, allow anonymous logins" / "...user must supply password" support auto-registration. Modes "TLS, ignore client cert, ..." are slated for deprecation (client validation to become mandatory).
**Client registration**: (1) Auto: existing cert (Classic KeySecure/old CM/external CA) must be signed by CA trusted on the interface; `ksctl clientmgmt tokens create`; `ksctl interfaces modify ... -a true -r <regtoken>` (-r mandatory if -a true); first connect w/ client cert registers it in the token's domain. External CA: add under External Certificate Authorities, then select in nae interface "External Trusted CAs". (2) Manual: create NAE client profile (JSON) -> create reg token from profile -> register client (get cert+key from local CA) -> connect. Delete: UI Application Data Protection > Legacy clients > Registered Clients.
**Response envelope**: `<XResponse>{ID,Success(true/false),FatalError|NonFatalError,ErrorString}`. Success=true in header may still be followed by error in data section. FatalError => server closes conn; NonFatalError => conn stays open.
**Requests** (all carry ID):
- User: UserCreate/Delete/Modify/Info/QueryRequest (non-admin only UserInfo else 220)
- Group: UserGroupCreate/Delete/AddUsers/RemoveUsers/Info/QueryRequest
- Key: KeyGenRequest, KeyVersionGenRequest (versioned keys only), KeyModify/KeyVersionModify, KeyDel, KeyInfo, KeyNames, KeyQuery, KeyClone, KeyImport/KeyVersionImport, KeyExport, PublicKeyExportRequest
- Secret: SecretObjectImport/Export/Info/Modify/Delete
- Cert/CA: CertificateExport, KeyCertificateExport, CAExport, CSRCreate (KeyName,CommonName,opt Org/OU/Locality/State/Country/EmailAddr/SignatureAlgorithm/ExtensionList), CertificateSign (local CA). CM CertificateName = cert ID (Classic = name).
- Crypto: RandGenRequest (Size chunks), CryptoRequest, RecordEventRequest{ID,MessageSize,Message} (logs in /opt/keysecure/logs or UI)
**Key elements**: KeyName, KeyAlias, IDType (Name|UUID|...; KeyVersion/AllVersions only with IDType Name), KeyVersion, AllVersions, Exportable/NonExportable, Aliases, KeyRotation, GenerateKeyID, Curveid, WrapKeyName/WrapPublicKey/WrapSymmetricKeyName/WrapFormat, Password/PasswordIdentifier (PBE wrap, PKCS12), custom attributes (base64 values).
**CryptoRequest**: `<CryptoRequest><ID/><Operations><Operation/><KeyName/><Algorithm/>[Charset][KeyVersion][WithAllActiveVersions][IV][TagLen 4-16 GCM only][Send][EphemeralPubKey,MacData EC decrypt][SaltLength RSA sign]</Operations>[Base64]</CryptoRequest>` + data elements. Operation: ENCRYPT DECRYPT MAC MACV SIGN SIGNV (HASH needs no key). Multiple Operation = chained; each acts on previous result; Send returns intermediate result.
**Data**: one of Data/Base64Data (chunked, `<Size>n</Size>bytes`), DataSingle/Base64DataSingle (single chunk <3500 B, faster). IV is hex-ASCII (DESede 8B, AES-CBC 16B, GCM 1-16B, 12 recommended; none for ECB); for MACV/SIGNV the IV element holds hex MAC/signature; 1 byte result 1/0. FPE results ASCII; FPE needs Charset (avoid predefined "All Printable ASCII"; custom 0021-007E). Batch: wrap multiple data elements in `<Batch>` (own context each, own IV/TweakData/TweakAlgorithm); no batching MAC/sign/chained ops.
**Algorithms**: AES/{CBC,ECB}/{NoPadding,PKCS5Padding}, AES/GCM, AES/CTR, AES-CMAC, DESede/{CBC,ECB}, ARIA, SEED, HMAC-SHA1/256/384/512, RSA (+SHA*withRSA, /PSSPadding), EC, FPE/AES/{CARD10,UNICODE}, FPE/FF3-1.
**Versioned keys**: set `/v1/configs/properties/NAE_KEY_VERSION_FOR_OPERATIONS` value `latest_active_key_version` before crypto with versioned keys.
**Error ranges** fatal/nonfatal: General 1-99/1001-99; Parse 100-199/1100-99; Auth 200-299/1200-99; Crypto 300-399/1300-99; Key 400-499/1400-99; User/Group 600-699/1600-99; Secret 1950-99. Fatal => closes conn.
**Key codes**: 40 No licenses installed; 41 All licenses in use; 45 Feature not activated; 50 SSL/TCP mismatch; 103 Header length cannot exceed 8192 bytes; 107 Unsupported protocol version; 109 Cannot negotiate version after previous requests; 111 Administrative operations disallowed; 202 Invalid username or password; 203 Cannot authenticate after previous requests; 204 Username did not match client certificate; 205 Could not connect to LDAP server; 207/208 token invalid/expired; 209 User password has expired; 220 Insufficient permissions; 230 Authentication required; 240 Client certificate required; 241 Invalid client certificate; 244 Client IP address did not match client certificate IP address field; 245 SSL connection failed (no shared ciphers); 303 Invalid padding; encrypted data may have been corrupted; 322 key version mismatch enc/dec; 1304 Invalid operation/algorithm pair; 1323 Invalid algorithm/key pair; 1324 NAE certificate is not valid for crypto, because it is inactive or unsigned; 1341 Algorithm requires IV; 1342 does not require IV; 1343 Invalid IV size; 1350 Could not decode ciphertext header; 1401 Unknown key name or insufficient permissions; 1404 key deleted or modified; 1405 Invalid key version; 1406 Key has no active versions; 1422 Key already exists; 1424/1425 key size; 1428 Maximum key capacity reached; 1440 Key is not exportable; 1450 not deletable; 1451 used by profiles; 1460 Security settings do not allow global key usage; 1473 Invalid ID Type; 1475 Unknown key alias; 1500-1561 cert errors (1529 Invalid or missing CA name; 1561 CA not found); 1602 User already exists; 1603 User does not exist; 1622 Password is too weak; 1643 Group does not exist; 1800 Communication failure; 1950 Secret Object already exists; 1955 Unknown Secret Object name or insufficient permissions.
**Passwords (CM)**: 9-29 chars, >=1 upper, lower, digit, special.

### Workflows
- **Encrypt**: connect TLS :9000 -> VersionRequest(2.10) -> AuthRequest -> `<CryptoRequest><ID>x</ID><Operations><Operation>ENCRYPT</Operation><KeyName>k</KeyName><Algorithm>AES/CBC/PKCS5Padding</Algorithm></Operations></CryptoRequest><Data><IV>hex16B</IV><Size>n</Size>BYTES</Data>` -> CryptoResponse{Success true} + `<Data><Size>m</Size>BYTES</Data>`. Decrypt: same IV, same key version.
- **GCM**: add TagLen; tag returned/verified (GMAC = auth only).
- **MAC verify**: Operation MACV, IV=hex MAC, Data=text; response 1 byte.
- **Key gen**: KeyGenRequest{ID,KeyName,Algorithm,KeySize,Exportable?,Permissions,...} -> KeyInfoRequest{KeyName|IDType UUID} to confirm; rotate: KeyVersionGenRequest (versioned keys).
- **Key export wrapped**: KeyExportRequest with WrapKeyName (or WrapPublicKey/WrapSymmetricKeyName/PBE Password) + WrapFormat; key must be Exportable.
- **Register client (manual)**: create nae client profile JSON -> `ksctl clientmgmt tokens create` -> register client w/ token (get cert/key) -> connect using client cert+key to NAE interface (verify-client-cert mode).
- **Auto-register**: trust CA on nae interface -> create token -> `ksctl interfaces modify -a true -r <token>` -> connect with existing client cert.
- **CSR**: CSRCreateRequest -> sign externally or CertificateSignRequest with local CA -> CertificateExportRequest.
- **Debug**: `sudo tcpdump -i <iface>` on CM to view traffic.

### Troubleshooting
- Connection closed right after Version/Auth -> out-of-order (VersionRequest first, then AuthRequest, immediately) -> codes 109/203; reorder, send once per connection.
- "Invalid username or password" (202) -> bad creds or wrong domain/LDAP prefix -> use `domain|ldap-conn|user` / `domain||user` forms.
- "Username did not match client certificate" (204) -> cert CN != AuthRequest user -> use matching user.
- "Client certificate required" (240)/"Invalid client certificate" (241) -> interface in verify-cert mode and client cert not signed by trusted CA / not registered -> add CA to interface (External Trusted CAs) or register client.
- "SSL connection failed (no shared ciphers)" (245) / "SSL/TCP mismatch" (50) -> client using plain TCP vs TLS interface, or cipher mismatch -> enable TLS client side, align ciphers.
- "Unknown key name or insufficient permissions" (1401) -> wrong name, or session unauthenticated (global user) -> authenticate as key owner/grant permissions.
- "Key is not exportable" (1440) / "Security settings do not allow key export" (112) -> key created without Exportable -> create with Exportable; policy.
- "Invalid padding; encrypted data may have been corrupted" (303) -> wrong key/version/IV or padding -> match enc params; set latest_active_key_version.
- "Key version specified in the CryptoRequest does not match..." (322) -> decrypt with encrypting version.
- "Operation requires..."/"Invalid operation/algorithm pair" (1304), "Invalid algorithm/key pair" (1323) -> algorithm type must match key type (e.g., AES key for AES/*).
- "Algorithm requires IV" (1341)/"Invalid IV size" (1343) -> IV must be hex-ASCII, correct length; none for ECB.
- "Header length cannot exceed 8192 bytes" (103) -> shrink header; put IV in data section/batch.
- "Key has no active versions" (1406) -> activate/create version (KeyVersionGenRequest).
- "NAE certificate is not valid for crypto, because it is inactive or unsigned" (1324) -> activate/sign the cert.
- "No licenses are installed" (40)/"All licenses are in use" (41) -> install/free license.
- "Insufficient permissions" (220) on user/group requests -> only admin may; non-admin limited to UserInfoRequest.
- Auto-register not working -> interface mode not a "verify client cert" mode, or -r token missing with -a true.
